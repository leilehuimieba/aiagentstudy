输出：从A地到B地的最少加油次数k以及最优解x\[1..k\]（x\[i\]表示第i次加油的加油站序号），若问题无解，则输出no
solution。

d\[n+1\]=s; //设置虚拟加油站第n+1站。

for i=1 to n

if d\[i+1\]-d\[i\]\>m then

output "no solution"; return //无解，返回

end if

end for

k=1; x\[k\]=1 //在第1站加满油。

s1=m //s1为用汽车的当前油量可行驶至的地点与A点的距离

i=2

while s1\<s

if d\[i+1\]\>s1 then //以汽车的当前油量无法到达第i+1站。

s1=d\[i\]+m //刷新s1的值

end if

i=i+1

end while

output k, x\[1..k\]
