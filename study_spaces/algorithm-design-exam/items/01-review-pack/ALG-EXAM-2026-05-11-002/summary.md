## 必背模块

### 1. 复杂度分析

必背：

- 大 O、Ω 的含义
- 最好 / 最坏 / 平均时间复杂度
- 时间复杂度 vs 空间复杂度
- 常见数量级比较：`O(1) < O(logn) < O(n) < O(nlogn) < O(n^2) < O(2^n)`
- 递归方程的基本判断
- 二分搜索 / 归并排序 / 快速排序 / 0-1 背包回溯的复杂度

典型考法：

- 单选题直接问复杂度
- 填空题让你补 `O(...)`
- 计算题让你分析递归式

### 2. 分治法

必背：

- 分治三步：**分解 -> 解决子问题 -> 合并**
- 可用分治法的问题特征：
  - 子问题与原问题同类型
  - 子问题规模变小
  - 子问题相互独立或重叠不明显
  - 子问题解可合并
- 典型题：
  - 二分搜索
  - 归并排序
  - 快速排序
  - 棋盘覆盖
  - 循环赛日程表
  - Strassen 矩阵乘法

### 3. 动态规划

必背：

- 两大要素：
  - **最优子结构**
  - **重叠子问题**
- 基本步骤：
  1. 定义最优解 / 状态
  2. 写出递推关系
  3. 计算最优值
  4. 必要时构造最优解
- 典型题：
  - 矩阵连乘
  - 最长公共子序列 LCS
  - 字符串编辑距离
  - 0-1 背包
  - 凸多边形最优三角剖分

### 4. 贪心法

必背：

- 两个核心点：
  - 贪心选择性质
  - 最优子结构
- 和动态规划的关键区别：
  - 贪心是**局部最优直接推进**
  - 动态规划是**系统比较所有状态后得到全局最优**
- 典型题：
  - 哈夫曼编码
  - 最优装载
  - 最小生成树
  - 单源最短路径（Dijkstra 场景下）

### 5. 回溯法

必背：

- 本质：**深度优先搜索 + 剪枝**
- 常见解空间树：
  - 子集树
  - 排列树
- 典型题：
  - N 皇后
  - 图的 m 着色
  - 旅行售货员
  - 0-1 背包
- 典型问法：
  - 采用什么搜索顺序
  - 解空间树属于哪一类
  - 剪枝函数 / 约束函数的作用
  - 空间复杂度为什么通常与树高有关

### 6. 分支限界法

必背：

- 和回溯法相同点：都要在解空间树中搜索
- 和回溯法不同点：
  - 回溯法一般是深度优先
  - 分支限界法更强调**活结点表**与**界函数**
- 典型组织方式：
  - FIFO 队列式
  - 优先队列式
- 典型题：
  - 最大团
  - 旅行售货员
  - 0-1 背包

### 7. NP 理论与随机算法

必背：

- `P ⊆ NP`
- NP 完全问题的含义
- 常见随机算法名字辨析：
  - 蒙特卡罗
  - 拉斯维加斯
  - 舍伍德
- 常见考法是概念选择题，不一定要求深入证明

## 优先级排序（考前冲刺版）

如果时间只够复习一天，优先顺序建议：

1. 复杂度分析
2. 动态规划
3. 回溯法
4. 贪心法
5. 分治法
6. 分支限界法
7. NP / 随机算法
