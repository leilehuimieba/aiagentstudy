## 1. 分治题模板

### 适用题

- 二分搜索
- 归并排序
- 快速排序
- 棋盘覆盖
- 循环赛日程表

### 答题模板

1. 说明如何将原问题分解为若干个规模更小的同类子问题。
2. 说明子问题之间是否独立。
3. 说明子问题解如何合并。
4. 写出递归式。
5. 给出时间复杂度。

### 标准表述

> 该问题满足分治法要求：原问题可分解为若干规模更小的同类子问题；子问题求解后可有效合并；随着递归推进，问题规模不断缩小直到基本情形。

## 2. 动态规划题模板

### 适用题

- 0-1 背包
- LCS
- 矩阵连乘
- 编辑距离

### 答题模板

1. 定义状态 `dp[i][j]` 或 `dp[i]`
2. 说明状态含义
3. 给出边界条件
4. 写转移方程
5. 说明计算顺序
6. 说明时间 / 空间复杂度

### 标准表述

> 先刻画问题的最优子结构，再定义状态表示子问题最优值，随后建立状态转移方程，自底向上计算整个表，最终得到原问题最优解。

### 你考试里最该熟的两个动态规划模型

- **LCS**：两个序列前缀的最优值
- **编辑距离**：删除、插入、替换三种操作最小代价

## 3. 贪心题模板

### 适用题

- 哈夫曼编码
- 最优装载
- 最小生成树
- Dijkstra 场景最短路

### 答题模板

1. 给出贪心策略
2. 说明为什么每一步局部最优是安全的
3. 说明排序 / 堆 / 优先队列如何支持实现
4. 给出复杂度

### 标准表述

> 算法在每一步都作出当前看来最优的选择，并且该选择不会破坏全局最优性，因此可以用贪心策略求解。

## 4. 回溯题模板

### 适用题

- N 皇后
- 图着色
- 旅行售货员
- 子集选择问题

### 答题模板

1. 定义解空间树是子集树还是排列树
2. 说明结点表示什么
3. 写递归搜索过程
4. 写约束函数 / 剪枝函数
5. 说明搜索顺序是深度优先
6. 给出复杂度上界

### 标准表述

> 回溯法按深度优先方式搜索解空间树；当发现当前部分解不可能扩展成可行解或最优解时，立即回退，从而减少无效搜索。

## 5. 分支限界题模板

### 适用题

- 最大团
- 旅行售货员
- 0-1 背包

### 答题模板

1. 明确活结点表的组织形式
2. 定义上界 / 下界 / 估价函数
3. 说明扩展哪个活结点
4. 说明何时剪枝
5. 给出结果

### 标准表述

> 分支限界法通过界函数估计当前结点的最优可能值，并据此决定扩展顺序或剪去不可能产生更优解的分支。

## 6. 复杂度分析题模板

### 常见答题句式

- 循环执行 `n` 次，因此复杂度为 `O(n)`。
- 每次规模减半，因此递归深度为 `O(logn)`。
- 每层代价为 `O(n)`，共有 `O(logn)` 层，因此总复杂度为 `O(nlogn)`。
- 最坏情况下递归树结点数指数增长，因此复杂度为 `O(2^n)`。
