# 复习计划（初版）

## 目标

把当前零散题库整理成一个适合考前反复回顾的复习闭环：

`范围 -> 题型 -> 模板 -> 错题 -> 冲刺卷`

## 建议四步法

### 第 1 步：定范围

优先读：

- `算法分析与设计期末考试复习题纲完整版.doc`
- `《算法分析与设计》期末考试复习题.pdf`

目标：

- 确认老师常考哪些章节
- 列出“定义题 / 计算题 / 证明题 / 设计题 / 套卷题”五种题型

### 第 2 步：刷基础题

优先做：

- `算法分析与设计期末考试习题题目练习学生版.doc`
- 其他带“复习题”“题库”的资料

目标：

- 把每道题归类到知识点模块
- 形成“这一类题的标准解法模板”

### 第 3 步：做整卷

优先做：

- 所有带“试卷 / 试题 / 期末卷”的文件

目标：

- 限时完成
- 统计易错点
- 找出最薄弱的 2~3 个模块

### 第 4 步：考前冲刺

优先看：

- `【算法设计与分析】合并PDF.pdf`
- `算法设计与分析期末试题汇总.doc`
- `（完整版）算法设计与分析考试题及答案.doc`

目标：

- 只背高频定义、经典模板和错题
- 不再全面铺开，避免时间失控
