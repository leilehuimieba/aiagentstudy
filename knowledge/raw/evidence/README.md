# evidence/

Raw page/source captures that back a specific captured item (provenance for how a
page looked when it was ingested). Moved out of `knowledge/raw/` root. Read-only.

Families:

- `bestblogs-*.{html,txt,xml}` — BestBlogs site/page/API captures
- `http-*-page*.html` — fetched article/podcast/video page HTML
- `*-extract.txt` — text extracted from a captured page
- `BB-*-state.txt`, `BB-*-html.html` — early per-item page-state captures
- `*.png` — screenshots
