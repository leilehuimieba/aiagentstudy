# Knowledge Map

## Topic Directories

- `01-context-memory`: context engineering, memory, RAG, knowledge bases, progressive disclosure.
- `02-tools-actions`: OpenCLI, browser tools, APIs, CLI adapters, MCP-like tool surfaces.
- `03-control-loop`: planning, ReAct, orchestration, workflows, multi-agent coordination.
- `04-evaluation-guardrails`: reliability, CI, verification, safety, observability.
- `05-security-techniques`: offensive security techniques, web vulnerability detection, exploit methodology, CTF domain knowledge.
- `06-frontier-radar`: new models, products, papers, benchmarks, ecosystem updates, including CTF-agent benchmarks.

## Agent Loop

`Goal -> Context/State -> Reasoning/Planning -> Tool Action -> Observation -> Update -> Deliverable`
