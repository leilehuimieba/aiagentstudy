# AI Paper Sources

## Primary Paper Feeds

### arXiv

Use for broad daily coverage.

Recommended categories:

- `cs.AI`: artificial intelligence
- `cs.CL`: natural language processing and LLM papers
- `cs.LG`: machine learning
- `stat.ML`: statistical machine learning
- `cs.CV`: multimodal and vision-language models
- `cs.SE`: software engineering agents and AI coding
- `cs.CR`: AI security and cyber agents
- `cs.HC`: human-computer interaction and AI workflows

Recommended query themes:

- `agent OR agents OR agentic`
- `"large language model" OR LLM`
- `"context engineering" OR retrieval OR RAG`
- `"tool use" OR "function calling"`
- `"computer use" OR "web agent" OR "browser agent"`
- `"pretraining" OR "post-training" OR "alignment" OR "RLHF" OR "DPO"`
- `"inference optimization" OR quantization OR KV cache OR speculative decoding`

### OpenReview

Use for ICLR, NeurIPS, ICML, TMLR and other peer-review metadata.

Best for:

- accepted conference papers,
- reviews and decisions,
- benchmark and evaluation papers,
- follow-up discussion around reproducibility.

### Hugging Face Papers

Use for daily trending AI papers and community-prioritized research.

Best for:

- fast discovery,
- papers with model/card/code/project links,
- early community signal.

### Semantic Scholar

Use for metadata enrichment:

- authors,
- citations,
- references,
- TLDR,
- venue,
- open-access PDF links.

### ACL Anthology

Use for NLP, LLM, retrieval, tool-use, and agent language papers.

### Conference Proceedings

Use for authoritative accepted-paper lists:

- NeurIPS
- ICML
- ICLR
- ACL / EMNLP / NAACL
- COLM
- AAAI
- IJCAI

## Secondary Research Discovery

- alphaXiv: discussion layer around arXiv papers.
- Papers with Code: task/benchmark/code linkage.
- GitHub Trending: code release signal.
- X/Twitter lists and Bluesky: early signals only, not primary evidence.
- Reddit / Hacker News: discussion and skepticism layer.

## Capture Depth

Use three levels:

1. `metadata`: title, authors, abstract, source IDs, links.
2. `summary`: structured model/agent mapping and why it matters.
3. `full`: PDF/HTML full text and extracted evidence.

Only promote to `full` when:

- it is directly relevant to AI agents,
- it changes our mental model,
- it introduces a method worth implementing,
- it is a benchmark/eval source,
- it is a model training/optimization paper worth tracking.
