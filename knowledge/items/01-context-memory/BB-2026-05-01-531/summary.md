## Core Takeaway

The article, compiled by Founder Park from a blog post by Addy Osmani, Director of AI at Google Cloud, systematically introduces the emerging concept of 'Loop Engineering' in Silicon Valley AI circles. The core idea is: instead of manually prompting a coding Agent, design a system that allows the Agent to work in an automated loop. The article details the five core modules required for a complete Loop—Automations (automatic triggering), Worktrees (parallel isolation), Skills (solidifying project knowledge), Plugins & Connectors (tool integration), Sub-agents (separation of generation and checking)—along with a state file for persistent memory. Using Claude Code and Codex as examples, it shows how these modules are implemented in the two products and provides a complete daily Loop example. Finally, the author emphasizes the irreplaceable role of humans in Loop engineering: verification responsibility, code understanding debt, and the risk of cognitive surrender, pointing out that designing a Loop is harder than prompt engineering, and engineers must build with judgment.
