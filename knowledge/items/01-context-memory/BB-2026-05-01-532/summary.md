## Core Takeaway

This is an in-depth technical practice article from the Tencent Cloud Developer official account. Author franslee, based on the practical experience of his team's AI data analysis assistant Dola, systematically explores two core propositions for frontend development in the AI era. The first part focuses on "Serving AI Products Well," detailing how a three-dimensional scoring recommendation engine combining data features, SQL features, and user prompts improved chart recommendation accuracy from 55% to nearly 90%. It also covers the self-developed Code Highlighting Component 3.0 based on the CSS Custom Highlight API and multi-threaded architecture, solving pain points like selection loss during streaming dialogue, DOM explosion, and Ctrl+F unavailability. The second part focuses on "Serving AI Coding Well," proposing a Harness Engineering approach that advocates transforming legacy projects to be more suitable for AI collaboration by establishing machine-readable engineering rules, converging code exports, and extracting Design Tokens. The article also deeply reflects on how, in an era where AI-generated code is becoming mainstream, programming paradigms should shift from "elegant and concise" to "explicit, searchable, straightforward, and moderately repetitive." It points out that the role of frontend developers is transitioning from "syntax craftsmen" to "intention decomposers and architecture decision-makers."
