## Core Takeaway

This article profiles Jared Sires, an account executive at Anthropic who, despite having no prior coding experience, used Claude Code to build CLAFTS, an application that drafts customer email replies. The tool, built on roughly 4,300 lines of code written by Claude, integrates with Gmail, Google Drive, and web search to pull current product documentation and match Jared's writing style, saving him 10-15 hours per week. The success of CLAFTS led to a role shift: Jared is now a GTM product manager, building a suite of Claude-powered tools for the entire sales organization. These tools, packaged as a plugin for Claude Cowork, include daily briefs, customer context retrieval, pipeline management, and automated follow-up emails. The article details his iterative development process, the impact on his team (80% adoption within months), and his broader vision for using AI to dissolve technical barriers and empower non-engineers to build solutions.
