## Key Evidence

Acon proposes context compression tailored to long-horizon agent tasks, explicitly compressing both environment observations and interaction histories. This decomposition is especially relevant for agents that must juggle large tool outputs over many steps.

## Practical Notes

The main transferable idea is source-aware compression: compress HTTP responses, command outputs, and reasoning history differently.
