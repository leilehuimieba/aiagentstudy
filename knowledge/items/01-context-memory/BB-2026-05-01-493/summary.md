## Core Takeaway

Using Hugging Face's AI Agent glossary as a blueprint, the article starts from the core insight — "An Agent is not a model, but a system centered around a large model that can call tools, receive feedback, and continuously complete tasks" — and progressively breaks down key concepts in the Agent ecosystem. It first clarifies the relationship between Model and Agent: the Model is core but not everything; an Agent needs Scaffolding (managing "how to think") and Harness (managing "how to run") to drive the execution loop. It then delves into the distinction between Context Engineering (managing the information the model sees at each step) and Policy (defining behavioral patterns), as well as the hierarchical differences among Tool (specific actions), Skill (reusable methods), and Sub-agent (independent sub-task Agent). Finally, it covers training-stage concepts like Environment, Rollout, Reward, and Trainer, completing the full-chain terminology system from building and deploying to training Agents. The article is clearly structured with apt analogies, suitable for readers seeking a systematic understanding of Agent concepts.
