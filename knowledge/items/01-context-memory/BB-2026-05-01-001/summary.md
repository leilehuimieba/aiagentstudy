## Core Takeaway

Agent workflows are replaceable, while accumulated domain knowledge is durable. A serious agent workflow should end by extracting reusable knowledge, not only completing the immediate task.

## Reusable Principles

- Treat knowledge as a first-class deliverable.
- Use progressive disclosure: global catalog -> category catalog -> full item.
- Track knowledge maturity: draft -> verified -> proven.
- Add lifecycle management: reference tracking, linting, conflict handling, and decay.
- End every serious workflow with an archive/extract step.
