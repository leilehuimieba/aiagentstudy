## Core Takeaway

Anthropic announces Claude Tag, a new way for teams to work with Claude, starting as a Slack integration. Users can grant Claude access to selected channels and tools, then tag @Claude to delegate tasks. Claude builds context from channel activity, can take proactive initiative, works asynchronously, and supports multiplayer collaboration. At Anthropic, 65% of the product team's code is now created via an internal version of Claude Tag. The feature is available in beta for Claude Enterprise and Team customers, with tight administrative controls over tool access, data permissions, and spending limits. It works with Opus 4.8 and replaces the existing Claude in Slack app.
