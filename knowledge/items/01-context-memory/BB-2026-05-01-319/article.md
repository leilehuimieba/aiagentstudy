## Key Evidence

ReSum tackles the context bottleneck of long-horizon search agents by periodically converting interaction history into compact reasoning-state summaries. Instead of treating summarization as archival, it turns summary objects into the state representation that future reasoning consumes.

## Practical Notes

This is directly relevant to compressing long HTTP / CLI / observation traces without losing task-driving signals.
