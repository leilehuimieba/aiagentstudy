## Abstract

OSWorld provides a scalable real-computer environment for multimodal agents across Ubuntu, Windows, and macOS. It includes 369 tasks across web apps, desktop apps, OS file I/O, and multi-application workflows, with detailed setup configurations and execution-based evaluation scripts.

## Key Evidence

- 369 real computer tasks.
- Each task includes initial-state setup and a custom execution-based evaluation script.
- Humans solve over 72.36% of tasks while the best model solves 12.24%.
