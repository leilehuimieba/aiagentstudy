## Key Evidence

SARIF defines a machine-readable result format with locations, artifacts, related locations, code flows, and attachments. Although designed for static analysis, it is a highly relevant reference for any security proof object that needs traceability and structured evidence.

## Practical Notes

The most transferable pieces are result-level evidence nodes and flow-like linkage between them.
