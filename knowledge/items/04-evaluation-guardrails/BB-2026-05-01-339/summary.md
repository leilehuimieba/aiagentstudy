## Core Takeaway

The article provides a detailed introduction to verify-data, an end-to-end data validation Agent Skill designed for data development teams. This skill automates the entire process through natural language interaction, from table structure retrieval, baseline table discovery, code logic analysis, validation SQL generation, execution, to report publishing. Core capabilities include a two-stage automatic baseline table discovery strategy, 10 standardized validation SQL templates, Code Diff-driven risk scanning, 4 degradation validation strategies, and automatic generation of review-grade reports.
