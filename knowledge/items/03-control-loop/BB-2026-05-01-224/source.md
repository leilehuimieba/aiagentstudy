- Description: Using 'AI Super Apps' as a starting point, the article explores a counterintuitive yet crucial trend in current AI technology evolution: as AI shifts from generating text to executing real-world tasks, it is not bypassing established software engineering systems but instead deeply embracing mature technologies like HTML, browsers, file systems, terminals, Git, and the MCP protocol. By analyzing Codex's distributed Agent workstation architecture (multi-track execution, sandbox isolation, decoupling of control plane and execution plane), Claude Cowork's workflow control, Ralph Loop's long-cycle task mode, the presentation layer debate between Markdown and HTML, Google A2UI's declarative UI approach, and Bun's migration from Zig to Rust, the author argues a core point: the ultimate form of AI is not a smarter model, but an 'action system' constrained and organized by classic engineering structures. The article emphasizes that this seemingly 'regressive' convergence is actually the restoration of order after a complex system matures, and an inevitable path for AI deployment.
