## Abstract

Reflexion proposes verbal reinforcement: agents reflect on task feedback in language, store the reflection in an episodic memory buffer, and use that memory in subsequent trials. The framework avoids weight updates and instead improves behavior via reusable linguistic feedback.

## Key Evidence

- Reflection is stored in episodic memory.
- The framework works with scalar or free-form feedback and with external or self-generated feedback.
- It significantly improves baseline agent behavior across reasoning, coding, and sequential decision tasks.
