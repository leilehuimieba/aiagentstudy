## Core Takeaway

This post explains how JetBrains selected Codex (powered by OpenAI) as the recommended coding agent in JetBrains AI. The evaluation used a benchmark dataset of real software engineering tasks across Java, C#, and Python, measuring solve rate, cost, and latency. After comparing candidates (including Junie with Gemini models), Codex with GPT-5.4-mini medium reasoning emerged as the top performer in both offline benchmarks and online A/B tests. The article details the methodology, including cost constraints (avoiding more than 2% of users exceeding $20/month), and provides transparent data via the DPAIA repository. It also emphasizes that users can still switch agents freely.
