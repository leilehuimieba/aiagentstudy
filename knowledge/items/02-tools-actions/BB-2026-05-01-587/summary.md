## Core Takeaway

Kun Chen, ex-Meta L8 principal engineer, details his personal agentic engineering workflow that has enabled him to ship 30+ high-quality PRs per day. The setup is built entirely in the terminal: WezTerm, tmux, Neovim, and agent harnesses like Claude Code and OpenCode. Chen emphasizes writing prompts like a manager (asking for outcomes, not actions; explaining the why; giving feedback), using voice input for speed (OpenSuperWhisper), and planning complex work with interactive HTML artifacts via his open-source Lavish Editor. Implementation is fully autonomous once the plan is set, with agents validating their own changes end-to-end. The post uses a real project—'Hi Bit', an AI tutor for his son—as a concrete example.
