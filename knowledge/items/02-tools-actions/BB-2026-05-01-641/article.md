6 月 26 日，Notion 在 X 上发布了一条公告：将于 9 月 22 日在 Web、桌面端和 iOS 全面关闭 Notion Mail。

  这款 AI 邮箱客户端 2025 年 4 月才正式上线，总生命周期不过 17 个月。Notion 给出的理由很直接，随着 Agent 能力变得更强，越来越多用户将邮件工作流交给 Agent 处理。"如今，超过一半的 Notion Mail 用户在不打开收件箱的情况下管理邮件。因此，我们决定全面转向由 Agent 来管理你的收件箱。"

  

  AI 邮件一直是近年来最活跃的生产力赛道之一。一方面，围绕「AI + 邮件」的垂类初创公司持续涌现，并获得了规模不小的融资支持。另一方面，从 Gmail、Outlook 等大厂产品到各类通用工具，都在不断强化邮件处理中的 AI 能力。

  作为估值 110 亿美元的生产力软件独角兽，Notion 此次却干脆利落地终止了这款上线一年多的主要产品，果断 pivot 了。

  过去，AI 在邮件系统中的角色通常是增强体验，带来更好的分类、更智能的筛选、更自然的回复建议，本质仍然是在优化原有的邮箱界面。但如果 Agent 已经可以理解、处理并执行邮件任务，那么邮箱作为人类阅读与操作中介的必要性也开始下降。换句话说，邮件的未来可能不是让人用得更好，而是让人根本不用再看。

  01 

  邮箱曾是 Notion 挑战 Google Workspace 的重要一环

  Notion Mail 的故事始于 2024 年 Notion 对协作软件公司 Skiff 的收购。Skiff 此前以安全加密为核心卖点，产品包括加密文档协作、邮箱、日历、云盘等。但被收购后不到一年，Skiff 原有的邮件服务便被关闭。基于这支团队，Notion 在 2025 年 4 月正式推出了 Notion Mail，向所有用户开放。

  

  除了旗舰应用 Notion 本身，公司的生产力版图中还包括 Notion Calendar 和 Notion Web Clipper。Notion Mail 承载着 Notion 挑战 Microsoft Office 和 Google Workspace 的雄心，要成为用户所有工作的中心枢纽，就必须把邮箱做好。在 Notion 的构想中，Notion Mail 并非普通的 Gmail 客户端，其核心差异在于 AI 的深度嵌入。

  一方面，用户可以通过自然语言提示词实现对邮件的自动整理。比如直接写一句话，「按照招聘流程阶段为所有招聘邮件打标签，并显示对应岗位」，AI 就能自动执行分类，不再需要手动设置复杂的筛选条件。另一方面，Notion 也希望让 AI 接管繁琐的邮件往来，会议安排、后续跟进、重复性沟通等工作，统统都可以交给 AI 处理。

  

  前 Skiff 联创、Notion Mail 团队负责人之一 Andrew Milich 曾表示，他们的愿景是"重新定义收件箱"。比起永无止境的邮件列表，收件箱而应该成为一个数据库。用户可以像在 Notion 中一样，对它进行筛选、排序和组织。

  02

  Notion 的取舍：

  保留日历，让 Agent 吞掉收件箱

  Notion Mail 的宏大愿景在一年后便被按下了停止键。

  在官宣关停的推文下，不少 Notion Mail 用户表达了惋惜和不满。其中一名用户写道，「我始终认为需要一个专门的邮件界面。如果能在这个界面中同时配备 Agent，那当然更好，但我不希望只有 Agent。」

  这代表了当下一种相当现实的需求。即便 Agent 能够处理大部分邮件事务，用户仍然需要一个可见的界面，能够看到全貌、确认细节，在必要的时候手动干预。一个完全消失的收件箱界面，某种程度上也消解了人的「掌控感」。

  但 Notion 产品负责人 Max Schoening 给出了不同的判断。他表示，Notion Mail 是团队尝试将「可塑软件」理念带入电子邮件领域的一次探索。但他们越来越相信，软件的未来在于替用户完成工作，而不仅仅是展示工作内容。

  他也坦言了做邮件客户端的现实困难。从功能细节、邮件解析、稳定性到安全性，每一个环节都是漫长的长尾工程。与其在这些地方持续投入，Notion 认为不如把精力集中在邮件的分类、整理和执行上。这是他们从用户行为中观察到需求更为强烈的方向，同时也正在加大对更低成本大模型的投入，强化 AI Agent 在邮件处理中的能力。

  

  一个值得注意的对比是，Notion Calendar 这款 2024 年初上线的日程管理应用并未受影响。Max Schoening 的解释是，时间本质上是一种高度视觉化的信息，天然需要一个界面来呈现。而邮件主要是文本内容，可以自然地存在于聊天线程、数据库等各种形态中，不一定非要有一个专门的收件箱。

  也就是说，在 Notion 的判断里，日历仍然需要 GUI，但邮件可以被 Agent 吞掉。既然看到了这个趋势，Notion 就选择立刻行动，哪怕代价是关停一款上线一年的产品。在快速变化的市场里，及时止损本身就是一种能力。

  03

  给 Agent 一个独立的邮箱正成为新趋势

  在 Notion Mail 的关停帖子下，不少 AI 邮箱类产品纷纷「接盘式」发声，希望承接可能流失的用户。但如果仔细看这些公司的产品方向，它们更像是在沿着 Notion 的思路前进，试图打造专门为 AI Agent 服务的邮件系统。

  以创业公司 AgentMail 为例，其联合创始人兼 CEO Haakam Aujla 曾表示，他们从一开始就希望为 AI Agent 提供与 Gmail 类似的邮箱能力，但去掉所有为人类设计的界面元素。「我们希望 Agent 具备搜索、过滤、回复和转发的能力，但它们不应该像人一样点击屏幕上的按钮。对 Agent 来说这太笨重了，它们只需要调用 API 即可。」当然，他们的平台也保留了一个管理界面，供用户查看和管理 Agent 邮箱。

  国内方面，腾讯也在探索类似的方向。6 月 23 日，QQ 邮箱推出了 Agent Mail，定位为"一款专为 Agent 设计的邮箱"。它与用户的个人邮箱完全隔离，AI 仅能访问专属邮箱内的内容。同时它不只是一个收件箱，还是 Agent 的独立对外身份，可以自主注册平台、接收验证码，甚至支持企业间 A2A 自动完成询价和订单对接。

  

  这背后的逻辑在于，当 Agent 开始替人办事，它需要的不是一个更好的收件箱界面，而是一套独立的通信基础设施，有自己的身份、自己的权限边界、自己的审计记录。

  04

  该考虑给 AI Agent 开发产品了

  两年前，AI 大多还只是能调用简单工具的聊天机器人。今天，Coding Agent 已经在全球普及，人们开始用 Agent 管理日历、安排会议、搭建营销活动。如果科技行业的判断实现，未来互联网上 AI Agent 的数量甚至可能与真人用户相当。

  在这一趋势下，邮件这个品类正在被重新定义：

  
   
    对部分用户来说，邮件的未来是"没有收件箱"。Agent 直接读取、处理、执行，用户只看结果。

   

   
    对 Agent 本身来说，它需要自己的邮件身份和通信能力，而不是借用人类的账号。

   

   
    对邮件类创业公司来说，竞争对手可能不再是另一个更好的收件箱，而是"收件箱"这个概念本身的消失。

   

  

  当然，这不意味着所有人都准备好了把邮件完全交给 AI。邮件涉及沟通、决策、承诺、法律效力，它不像日程安排那样可以容错。在 Agent 的可靠性达到足够高的水平之前，"没有收件箱"对大多数人来说仍然是一个过于激进的承诺。

  但深层的转变是，过去的变革方向是 AI Mail，在传统邮件产品上叠加智能能力。而现在出现的新路线是 Mail for AI，直接为 Agent 之间的通信与执行而设计。

  如果这一逻辑成立，那么"老产品 + AI"的思路本身可能只是一个过渡态，真正的方向是给 Agent 造出新工具。邮件如此，日程管理、项目协作、CRM 是否也会走向同样的终局？当 Agent 成为主要的工作执行者，生产力软件或许都将面临同一个问题：你到底是在为人做工具，还是在为 Agent 做工具？
