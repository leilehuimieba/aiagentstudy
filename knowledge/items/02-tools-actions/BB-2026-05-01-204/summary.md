## Core Takeaway

This Cursor changelog announces a major update focused on development environments for cloud agents. The release introduces multi-repo environment support, allowing agents to work across multiple repositories with session reuse. It improves Dockerfile-based environment configuration as code, including build secrets for secure access to private registries and upgraded layer caching for 70% faster builds. The update also enhances agent-led environment setup with interactive validation and clear failure handling. New governance and security controls include environment version history with rollback, admin permissions, audit logs, and scoped egress and secrets. These features enable teams to run fleets of parallelized agents that can take engineering tasks from start to finish within fully controlled environments.
