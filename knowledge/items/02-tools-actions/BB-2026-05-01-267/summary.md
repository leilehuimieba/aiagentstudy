## Core Takeaway

This article from the Google Developers Blog announces the launch of version 0.1.0 of the Agent Development Kit (ADK) for Kotlin, along with a specialized ADK for Android library. The framework is designed to simplify the development of AI agents, particularly for hybrid cloud-edge scenarios. A key feature is hybrid orchestration, where a cloud-based agent can delegate specific tasks to sub-agents running entirely on-device using models like Gemini Nano. This approach enhances privacy by keeping sensitive data processing local while leveraging the reasoning power of cloud models. The article provides code examples for setting up agents, defining tools with annotations, and creating multi-agent systems. It also outlines the core feature set, including support for LLM-based, workflow-based, and custom agents, MCP and A2A integrations, session state management, and telemetry. The release is positioned as an experimental first step, with the goal of empowering developers to build intelligent, privacy-conscious applications on Android and beyond.
