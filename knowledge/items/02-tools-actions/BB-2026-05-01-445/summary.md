## Core Takeaway

Addressing the core contradiction between the rapid iteration of business Agents and the slow construction of traditional evaluation engineering, this article proposes a "Harness Engineering Building" evaluation scheme. The core idea is to use a powerful Agent (Claude Code) as the builder and operator of the evaluation engineering, transforming the evaluation logic from traditional Python scripts into more flexible, readable, and easily iterable Agent prompts. The article details the three-layer architecture of Harness (Rule Layer, Data Layer, Execution Logic Layer, Output Layer), a unified three-layer metric framework (L1 General Foundation, L2 Capability Type, L3 Specific Metrics), and a five-step construction method from evaluation scheme design to result analysis. Through practical cases and efficiency comparisons (compressing the full process for a single Agent from 1.5 weeks to 1-2 days), it demonstrates significant advantages in scenarios such as Prompt iteration validation and multi-Agent horizontal comparison, and candidly discusses limitations like LLM-as-Judge bias and evaluation set scale. Originating from the frontline practice of the Alibaba Cloud Developer Team, the methodology is complete and highly actionable.
