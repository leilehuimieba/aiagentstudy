AssemblyAI April 2026 Product Recap

AssemblyAI has announced a suite of significant updates and new model releases designed to enhance accuracy, vertical specialization, and developer ease-of-use.

High-Accuracy Streaming and Medical Specialization

The headline release is Universal 3 Pro streaming, a new model specifically optimized for detecting complex entities like emails and phone numbers with high precision. For the healthcare sector, AssemblyAI introduced Medical Mode. This feature allows medical scribes and notetakers to capture specialized terminology accurately using just a single parameter, eliminating the manual configuration of key terms.

Building Voice Agents

The new Voice Agent API simplifies the creation of real-time conversational AI. Operating via a websocket, the API manages the heavy lifting of voice interaction, including:

Tool calling
Turn detection
Automatic reconnection

Developers can also leverage the new Docs MCP server and Claude code skills to integrate these agents into their existing environments.

LLM Gateway and Language Support

The LLM Gateway has expanded to include several cutting-edge models: Opus 4.7, Kimmy 2.5, Quen 3, and GPT 5.5. Additionally, language support for Hebrew and Swedish has been improved in the Universal 2 model, with more languages expected soon.

Enhanced Data Privacy

New updates to PII (Personally Identifiable Information) reduction now allow developers to request both redacted and unredacted versions of a transcript in a single request, streamlining the workflow for applications that require sensitive data handling.
