## Core Takeaway

This article reports on a new AWS capability that allows AI agents to interact with legacy desktop applications through Amazon WorkSpaces as managed virtual desktops. Instead of requiring API integration or expensive modernization, agents use computer vision to take screenshots and simulate human inputs like clicking, typing, and scrolling. The approach addresses a widespread problem: according to a 2024 Gartner report, 75% of organizations run legacy applications without modern APIs, and 71% of Fortune 500 companies rely on mainframe systems without adequate programmatic access. By giving agents the same desktop interface a human employee would use, AWS provides a practical bridge for deploying AI in environments with entrenched legacy systems. The article highlights the technical architecture, including IAM authentication and pre-signed URLs, and positions this as a pragmatic alternative to full-scale modernization projects.
