# AI Agent Learning Model

An AI agent is a system that uses a model to pursue a goal through a control loop:

`Goal -> Context/State -> Reasoning/Planning -> Tool Action -> Observation -> Update -> Deliverable`

## Building Blocks

1. Model
2. Goal
3. Context/State
4. Tools/Actions
5. Control Loop
6. Memory
7. Evaluation/Guardrails
