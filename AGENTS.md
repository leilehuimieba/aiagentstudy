# Workspace Rules

Before answering user questions in this workspace, read:

1. `README.md`
2. `AI_AGENT_MEMORY.md`
3. `docs/AI_AGENT_LEARNING_MODEL.md`
4. `docs/OPENCLI_NOTES.md`
5. `docs/KNOWLEDGE_BASE.md`

Knowledge-base rule:

1. Read `knowledge/catalog/README.md`.
2. Read `knowledge/catalog/map.md`.
3. Read `knowledge/catalog/articles-index.md`.
4. Read only relevant `knowledge/items/**/summary.md`.
5. Read full `article.md` only when needed.

When collecting items, capture full article text if available. Also record evidence links in `source.md`: the BestBlogs URL and the original publisher URL when BestBlogs exposes it.

Answer in Chinese by default.
